\# 📊 **HR Performance Dashboard**

\## 📌 Project Overview



The \*\*HR Performance Dashboard\*\* is an interactive Excel dashboard designed to analyse employee workforce data and provide a clear view of key HR performance metrics.



The dashboard focuses on employee headcount, attendance, performance scores, training hours, and workforce distribution across departments, genders, job titles, and locations.



\---



\## 🎯 Project Objectives



\- Analyse overall employee headcount.

\- Monitor average employee attendance.

\- Evaluate average employee performance.

\- Track total training hours.

\- Compare employee distribution across locations.

\- Analyse department-wise and gender-wise headcount.

\- Analyse workforce distribution by job title.

\- Provide interactive filtering for HR data analysis.



\---

\## 📊 Key Performance Indicators



The dashboard includes four major KPIs:



\### 👥 Head Count

Displays the total number of employees and their gender distribution.



\### 📅 Average Attendance %

Shows the average employee attendance percentage.



\### ⭐ Average Performance Score

Represents the overall employee performance using a 5-star rating format.



\### 🎓 Training Hours

Displays the total training hours completed by employees.



\---



\## 📈 Dashboard Analysis



\### 1. Head Count by Location \& Gender



This chart compares the number of male and female employees across different locations, including:



\- Boston

\- Chicago

\- Los Angeles

\- New York

\- San Francisco



This helps identify workforce distribution across locations.



\---



\### 2. Head Count by Department \& Gender



This analysis compares male and female employee headcount across departments such as:



\- Finance

\- HR

\- IT

\- Marketing

\- Operations

\- Sales



This provides visibility into workforce composition across departments.



\---



\### 3. Gender Analysis



The dashboard provides a gender-wise employee distribution through the Head Count KPI.



The displayed dashboard shows a nearly balanced distribution between male and female employees.



\---



\### 4. Job Title Analysis



The Job Title slicer allows users to filter the dashboard based on different employee roles, including analyst, assistant, associate, executive, and other available job titles.



\---



\### 5. Location Analysis



The Location slicer allows users to filter the dashboard by employee location and dynamically analyse workforce metrics.



\---



\## 🎛️ Interactive Filters



The dashboard contains slicers for:



\- \*\*Department\*\*

\- \*\*Gender\*\*

\- \*\*Job Title\*\*

\- \*\*Location\*\*



These filters allow users to interactively explore the HR dataset and analyse specific employee groups.
